## About Me

I build and run production software. At **The Sod Boys** I built and now administer a field-operations platform (crew dispatch, GPS timeclock, fleet, inventory and payroll) used daily by a live business through a web dashboard and a WhatsApp-based AI agent. I own its uptime, backups and disaster recovery on Oracle Cloud and PostgreSQL.

Before moving into IT, I spent years in physical security operations (access control, video surveillance, incident response) and did IT help-desk work, so I care about reliability, documentation and doing the unglamorous parts of the job well. I'm studying networking at Algonquin College and looking for co-op and internship roles in software, cloud/systems administration, networking and cybersecurity.
